## Noch zu ergänzen, bevor du hochlädst:
1. Deine Coaching-Site-Datei aus dem anderen Chat/Projekt hier in diesen Ordner legen
   und in "index.html" umbenennen (das wird deine Startseite).
2. Optional: in setup-guide.html und setup-diagnose-tool.html ganz unten im
   CONFIG-Objekt den ctaUrl-Link eintragen (z. B. Link zurück auf index.html
   oder deine Buchungs-URL).

## Hochladen (GitHub Pages)
1. Neues Repository anlegen (z. B. christianseitz-website)
2. Add file -> Upload files -> ALLE Dateien aus diesem Ordner auf einmal reinziehen
   (index.html, setup-guide.html, setup-diagnose-tool.html)
3. Settings -> Pages -> Source: Deploy from a branch -> main -> / (root) -> Save
4. Nach ca. 1 Minute ist alles live unter:
   https://DEINUSERNAME.github.io/REPONAME/
   https://DEINUSERNAME.github.io/REPONAME/setup-guide.html
   https://DEINUSERNAME.github.io/REPONAME/setup-diagnose-tool.html

Diese drei Links dann in Discord posten (Coaching-Site verlinkt intern auf die
anderen beiden, oder direkt einzeln teilen).
